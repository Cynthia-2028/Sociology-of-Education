## 快速上手

- 问理论：「文化资本是什么？怎么用？」
- 问现象：「用教育社会学解读'鸡娃'」
- 问证据：「扩招之后教育更公平了吗？」
- 选题：「给我 5 个教育社会学论文选题，中国情境优先」
- 评稿：「按评估清单检查这篇论文的引言和结论」

## 编写约定

- 全文不出现书名、篇名、期刊名、学者人名；理论以机制表述归属。
- 不宣称覆盖多少份文献，依据强度见下方审计。
- 每个实质性论断在回答时按 SKILL.md 路由协议标注证据强度：【综述共识】/【多篇一致】/【单篇实证】/【理论推断】。
- 涉及中国教育的表述采用教育公平、质量提升、招生制度改革的正面中性框架；不含政治敏感内容、种族与性别刻板归因。

## 依据强度审计（附录）

编写方式：基于一批教育社会学材料的结构与要点整合编写，逐份精读后提炼，非原文摘编。材料处理情况如下：

| 处理方式 | 份数 | 说明 |
|---|---|---|
| 全文机读、逐页精读 | 23 | 含专著、手册、期刊论文（约 3200 页），产出 20 份精读笔记 |
| 扫描版、未能机读 | 4 | 未从原文取材；其核心概念仅经由本批其他可机读材料间接覆盖 |
| 合计 | 27 | — |

质量流程：逐份精读笔记均带页码锚点 → 撰写时剥离人名与文献名 → 禁词机检（人名、书名号、覆盖数量表述）→ 合规扫描（剔除精读中标记的政治敏感、刻板归因等内容）→ 交叉引用核对。

已知限制：扫描版材料未直接取材；精读笔记中发现的原文自身数字瑕疵（约 40 处）未采纳为知识库论断；结论强度以 SKILL.md 的四级标注为准。
